# v45 — Final-output guiding rule (Email / Communication)

- **Guiding rule:** each session is attributed to its FINAL OUTPUT.
  - Inbox triage, or work that ends in an email (send, draft, reply, forward) → **Email workflows**, even if it synthesized Teams chats, channels or meetings along the way.
  - Otherwise, posting to Teams, or predominantly synthesizing across Teams channels/chats → **Communication workflows**.
  - Otherwise skill build/attach/install/review → Write or debug code; else the deliverable's category by PRIORITY.
- Detection uses the goal text and, when available, the session's actions (e.g. CreateDraftMessage, SendEmail, PostChannelMessage, ListChannelMessages).
- Builds on v44 (one category per session).
